## Rule one

If it does not change a decision this week, it is not a dashboard tile. It is decoration.

## Rule two

Every tile needs:

- an **owner**
- a **cadence** (daily / weekly)
- a **threshold** that triggers action

## Rule three

Prefer **exceptions** over totals. Totals are for board slides. Exceptions are for operators.

We publish a full example layout in the **Executive dashboard** module PDF.
